# Luke Perea — Personal Portfolio

Results-driven transformation leader based in El Paso, Texas.

## Live Site

**https://lukeperea.com**

## Tech Stack

- Single-file HTML + Tailwind CSS (via CDN)
- Font Awesome icons
- EmailJS for contact form
- Custom photography of the Franklin Mountains & Chihuahuan Desert

## Local Development

Simply open `index.html` in any browser. No build step required.

## Deployment (Recommended)

### Option 1: Vercel (Recommended)

1. Create a GitHub repository and push this folder
2. Go to [vercel.com](https://vercel.com) → Import Git Repository
3. Deploy (takes ~30 seconds)
4. Add custom domain in Vercel settings when ready

### Option 2: Netlify (Fastest)

1. Go to [netlify.com/drop](https://app.netlify.com/drop)
2. Drag the entire folder onto the page
3. Done

## Custom Domain

Once deployed, you can connect a custom domain (e.g. `lukeperea.com`) directly in Vercel or Netlify. Both services make this very easy.

## Contact Form

The contact form uses EmailJS. The public keys are intentionally visible (this is how EmailJS browser integration works). A honeypot field is included for basic spam protection.

## Updates

To update the live site:
- Make changes locally
- Commit and push to GitHub
- Vercel will automatically redeploy
